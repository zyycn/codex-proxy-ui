以轻量表面、清晰层级和紧凑控件呈现配置、状态与操作

## 组件分类

| 分类       | 内容                                                                         |
| ---------- | ---------------------------------------------------------------------------- |
| 基础       | 按钮、图标按钮、标签、动效图标                                               |
| 布局与导航 | 卡片、页头、分段选择、菜单项、滚动容器                                       |
| 表单       | 表单与字段、输入、数字输入、多行文本、选择、复选、单选、开关、颜色选择、滑块 |
| 数据       | 表格、分页、列设置、Markdown                                                 |
| 反馈       | 空状态、骨架屏、提示、弹窗、确认弹窗、气泡                                   |

每个组件示例都使用库中的实际实现，顶部主题切换会同步作用于示例
