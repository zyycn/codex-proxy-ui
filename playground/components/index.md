# 组件总览

按主组件查找交互示例，配置区只调整当前组件，表格的分页与列设置收在表格页面

用法代码可复制为独立 Vue 单文件组件，先按[安装指南](../guide/installation.md)接入样式与主题，API 默认值以组件自身定义为准

## 基础

| 组件                               | 用途                             |
| ---------------------------------- | -------------------------------- |
| [BaseButton](./button.md)          | 文本操作、不同强调程度与加载状态 |
| [BaseIconButton](./icon-button.md) | 带可访问名称的紧凑图标操作       |
| [BaseTag](./tag.md)                | 状态、类别与短标签               |
| [BaseMotionIcon](./motion-icon.md) | 指针交互与减少动态效果适配       |
