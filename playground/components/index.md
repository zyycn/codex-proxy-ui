# 组件总览

全部 30 个公开组件都有可操作示例，示例直接引用库源码，支持明暗主题切换

## 基础

| 组件                               | 用途                             |
| ---------------------------------- | -------------------------------- |
| [BaseButton](./button.md)          | 文本操作、不同强调程度与加载状态 |
| [BaseIconButton](./button.md)      | 带可访问名称的紧凑图标操作       |
| [BaseTag](./display.md)            | 状态、类别与短标签               |
| [BaseCard](./display.md)           | 内容分组与卡片容器               |
| [BaseMotionIcon](./motion-icon.md) | 指针交互与减少动态效果适配       |

| [BasePageHeader](./page-header.md) | 页面标题、副标题与操作区 |

| [BaseMenuItem](./menu-item.md)     | 菜单操作、禁用与危险状态 |
| [BaseScrollbar](./scrollbar.md)    | 统一外观的横向与纵向滚动 |
