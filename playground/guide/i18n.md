# 国际化

组件默认使用英文，语言包从 `@codex-proxy/ui/locale` 导入，支持 `en`、`zhHans`、`zhHant`，对应语言标识 `en`、`zh-Hans`、`zh-Hant`

繁体文案沿用简体措辞与语序，仅转换字形，不替换地区用词

```vue
<script setup lang="ts">
import { ZConfigProvider, ZPagination } from '@codex-proxy/ui'
import { zhHans } from '@codex-proxy/ui/locale'
</script>

<template>
  <ZConfigProvider :locale="zhHans">
    <ZPagination :total="100" />
  </ZConfigProvider>
</template>
```

`locale` 可以响应式切换，嵌套 Provider 优先使用最近的配置。组件显式文案和 slots 覆盖默认值，Teleport 弹层沿用所属组件的上下文。UI 库不读浏览器语言和本地存储，不修改 `html.lang`，应用负责自己的语言策略

## 命令式通知

通知在应用组件树之外渲染，需要通过工厂绑定应用已有的响应式语言，不另外维护一份通知语言状态

```ts
import { createNotification } from '@codex-proxy/ui'
import { en, zhHans, zhHant } from '@codex-proxy/ui/locale'
import { computed } from 'vue'
import { i18n } from './i18n'

const packs = { en, 'zh-Hans': zhHans, 'zh-Hant': zhHant }
const locale = computed(() => packs[i18n.global.locale.value])
export const notification = createNotification({ locale })
```

`createNotification` 接受语言包、ref 或 getter，使用与 Provider 相同的来源。已打开通知的默认标题和关闭标签随语言更新，调用方传入的标题和消息保持原样。直接导出的 `ZNotification` 使用默认英文

## 日期和其他文本入口

DatePicker 继承 Provider 的语言，也可传入 `UiLocale` 类型的 `locale` 单独覆盖。Day.js 地区标识只在库内转换，切换语言不改变已选择的日期和绑定值。`format` 和 `valueFormat` 控制显示与值格式，数据传输建议使用稳定的数字日期格式或 ISO 字符串

`v-loading` 的默认提示是英文，指令位于组件配置体系外，应用通过指令已有的 `text` 选项传入本地化文本

语言包的 `theme` 按稳定主题 ID 提供名称和说明，主题算法与颜色计算不依赖当前语言
