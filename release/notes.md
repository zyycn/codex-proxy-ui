# v0.13.5

## 问题修复

- 弹窗首次打开也播放入场动画，关闭后再回写状态，默认保留内容，可用 `destroy-on-close` 在退场后卸载
- 通知从所在一侧滑入，关闭时原地淡出；多行正文完整显示，图标顶对齐，同一角落的通知按实际高度补位
- 通知默认显示 4500 毫秒，悬停或键盘聚焦时暂停计时，支持四角定位、关闭回调和可选倒计时进度条

## 交互改进

- 日期时间选择器支持滚动或键盘选择时、分、秒，范围为空时分别提示开始时间和结束时间
- 日期范围的快捷选项与日历标题垂直对齐，选区底色贴合首尾日期，确认后焦点回到输入框
- 表格文本截断时可悬停查看全文，下拉选项的长描述和表单的长错误提示可换行阅读
- 单行与多行输入框默认关闭自动填充，可通过 `autocomplete` 指定用户名、密码等用途

## v0.13.3 修复

- 分段选择器在数据加载后直接显示选中项，键盘进入时跳过禁用选项
- 下拉选择框靠近视口边缘时自动内移，空间不足时向上展开
- 改善暗色面板上输入框、分段选择器和次级按钮的辨识度
- 提亮带底色的浅色浮层，减淡菜单与下拉面板的阴影

## 安装

```bash
pnpm add https://github.com/zyycn/codex-proxy-ui/releases/download/v0.13.5/codex-proxy-ui-0.13.5.tgz
```

需要 Node.js 24+、Vue 3.5+，包名为 `@codex-proxy/ui`
