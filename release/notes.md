# v0.13.3

## 问题修复

- 分段选择器在数据加载后直接显示选中项，键盘进入时跳过禁用选项
- 下拉选择框靠近视口边缘时自动内移，空间不足时向上展开
- 改善暗色面板上输入框、分段选择器和次级按钮的辨识度
- 提亮带底色的浅色浮层，减淡菜单与下拉面板的阴影

## 安装

```bash
pnpm add https://github.com/zyycn/codex-proxy-ui/releases/download/v0.13.3/codex-proxy-ui-0.13.3.tgz
```

需要 Node.js 24+、Vue 3.5+，包名为 `@codex-proxy/ui`
