# v0.6.1

## 修复

- 增强表格排序箭头的选中状态对比，保持原有尺寸、实心样式和表头文字颜色
- 分页按钮随页码长度自适应宽度，长数字完整显示，按钮高度保持不变
- 分页按容器实际宽度调整可见页码数量，单行放不下时隐藏每页条数选择框，保留翻页按钮与当前页码

## 安装

```bash
pnpm add https://github.com/zyycn/codex-proxy-ui/releases/download/v0.6.1/codex-proxy-ui-0.6.1.tgz
```

需要 Node.js 24+、Vue 3.5+，包名为 `@codex-proxy/ui`
